## Neu in dieser Version

- Das Overlay startet vollständig verborgen, auch wenn es in der letzten Sitzung sichtbar war.
- Beim Öffnen mit **⌘ + ^** wird die Maus automatisch freigegeben; eine zusätzliche Aktivierung entfällt.
- Nach dem Schließen erhält das Spiel die Steuerung zurück. Aktive Cheats bleiben eingeschaltet.
- GitHub Actions baut und prüft die App automatisch; Versions-Tags veröffentlichen ein Release mit App-ZIP und Prüfsumme.

Der kompakte Launcher mit Mac-App-Store-/Steam-Auswahl und getrenntem rotem
Uncut-Startknopf bleibt enthalten. Der rote Knopf benötigt den separat installierten
MAS-Uncut-Helfer. **F12** schaltet alle Cheats aus; bestätigte Netzwerksitzungen
sperren die Trainer-Funktionen.
